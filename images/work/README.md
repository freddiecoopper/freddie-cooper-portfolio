# Featured work images (home page)

- `grey/` the non-coloured tall images (about 1:3, for example 450 x 1400). These show by default.
- `colour/` the coloured versions. They fade in on hover.

Give the colour file the same name, size and crop as its grey file (for example `grey/offgrid.png` and `colour/offgrid.png`).
Until a colour file is added, that image stays grey on hover.
A new project also needs its paths in `js/content.js` (`feature`, `featureColor`), or upload both in the dashboard instead.
